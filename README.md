# InternOrbit

InternOrbit is a full-stack internship portal built to simplify the internship hiring process for both students and recruiters. The platform allows recruiters to post internship opportunities, while students can explore openings and apply through a clean and user-friendly interface.

This project was developed to gain practical experience in building a complete MERN stack application with authentication, role-based access, REST APIs, and real-world application workflows.

---

## Features

### Student

* Create an account and log in securely
* Browse available internships
* Apply for internships
* Track application status
* Manage profile

### Recruiter

* Register and log in
* Post internship opportunities
* Edit or remove internship listings
* View applications submitted by students
* Manage internship postings from a dashboard

### General

* JWT Authentication
* Role-based authorization
* Protected routes
* RESTful API architecture
* Responsive user interface
* AI chatbot for answering common queries

## Getting Started

Clone the repository:

```bash
git clone https://github.com/jain-akshat-05/InternOrbit.git
```

Install dependencies.

Backend:

```bash
cd backend
npm install
npm start
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```
